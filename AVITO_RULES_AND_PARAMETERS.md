# Мануал по генерации XML-файлов для автозагрузки Avito

## Общая структура XML-файла

```xml
<Ads formatVersion="3" target="Avito.ru">
  <Ad>
    <!-- Параметры объявления -->
  </Ad>
  <Ad>
    <!-- Следующее объявление -->
  </Ad>
</Ads>
```

**Важно:**
- Кодировка файла: UTF-8
- Максимум объявлений в файле: 50 000
- Названия параметров чувствительны к регистру (только латинские буквы)
- **Форма продажи:** всегда `Россыпью` для всех товаров (не продаём в мешках)
- **Использование параметров:** используем все параметры (обязательные и необязательные) по максимуму для создания максимального количества вариаций

---

## ОБЩИЕ ОБЯЗАТЕЛЬНЫЕ ПАРАМЕТРЫ (для всех типов товаров)

### 1. Идентификация
- **Id** (обязательный) — уникальный идентификатор в файле
  - Формат: `{тип_товара}_{ДД.ММ}_{номер}`
  - Пример: `sand_05.12_1`, `crushed_stone_05.12_1`
  - Правила: не более 100 символов, может содержать цифры, русские/английские буквы, символы `, \ / ( ) [ ] - =`
  - **КРИТИЧНО:** Id не должен повторяться и его нельзя менять после публикации

- **AvitoId** (необязательный) — ID объявления на Avito
  - Для новых объявлений: **НЕ ЗАПОЛНЯТЬ** (система создаст автоматически)
  - Заполнять только если добавляем уже существующее объявление в файл

### 2. Основные данные
- **Category** (обязательный) — категория
  - Значение: `Ремонт и строительство`

- **Title** (обязательный) — заголовок объявления
  - Максимум: 100 символов
  - **Запрещено:** указывать цену, контактную информацию, слово "продам"

- **Description** (обязательный) — описание товара
  - Максимум: 7500 символов
  - Можно использовать HTML-теги: `p`, `br`, `strong`, `em`, `ul`, `ol`, `li`
  - Для XML использовать CDATA: `<Description><![CDATA[<p>Текст</p>]]></Description>`

- **Address** (обязательный) — адрес размещения
  - Полный адрес до 256 символов
  - **ВАЖНО:** адрес должен быть добавлен в профиль Avito (Профиль → Адреса → Адреса для объявлений)
  - Альтернатива: использовать `Latitude` + `Longitude` или `SellerAddressID`

- **Images** (обязательный) — фотографии
  - Минимум: 1 фото, максимум: 10 фото
  - Формат: JPEG, PNG
  - Максимальный размер: 25 МБ на фото
  - Ссылки с Яндекс Диска: `<Image url="https://disk.yandex.ru/..."/>`
  - Можно указать несколько: `<Image url="url1"/><Image url="url2"/>`

- **Price** (необязательный) — цена в рублях (целое число)

### 3. Описание товара (обязательные)
- **GoodsType** (обязательный) — вид товара
  - Значение: `Стройматериалы`

- **AdType** (обязательный) — вид объявления
  - Значения: `Товар приобретен на продажу` или `Товар от производителя`

- **Condition** (обязательный) — состояние
  - Значения: `Новое` или `Б/у`

- **GoodsSubType** (обязательный) — подвид товара
  - Зависит от типа товара (см. разделы ниже)

## ТИП ТОВАРА: ПЕСОК (Сыпучие материалы)

### Специфичные обязательные параметры:

#### 1. Категория и тип
- **GoodsSubType**: `Сыпучие материалы`
- **BulkMaterialType**: `Песок`
- **BulkMaterialSubType** (обязательный) — подтип песка:
  - `Речной`
  - `Карьерный`
  - `Морской`
  - `Кварцевый`
  - `Перлитовый`
  - `Керамзитовый`
  - `Мраморный`
  - `Доломитовый`
  - `Термозитный`

#### 2. Условия продажи (форма: Россыпью)
**ВАЖНО:** Форма продажи всегда `Россыпью` для всех товаров.

- **PackagingType**: `Россыпью` (всегда)
- **CompactionCoefficient** (обязательный) — коэффициент уплотнения, т/м³
  - Диапазон: от 0 до 6
  - Пример: `1`, `1.5`, `2.0`, `1.2`, `1.8`, `2.5`
  - **Используем для вариаций:** разные значения для создания уникальности
- **MinSaleQuantity** (обязательный) — минимальный заказ, м³
  - Диапазон: от 0 до 500
  - Пример: `1`, `5`, `10`, `3`, `7`, `15`
  - **Используем для вариаций:** разные значения для создания уникальности
- **PriceFor** (обязательный) — единица измерения цены
  - Значения: `м³`, `тонну`
  - Пример: `м³` или `тонну`
  - **Используем для вариаций:** чередуем между `м³` и `тонну`

#### 3. Необязательные параметры (ИСПОЛЬЗУЕМ ВСЕ для вариаций)
**ВАЖНО:** Используем все необязательные параметры по максимуму для создания большего количества вариаций характеристик.

- **Color** (необязательный, но используем) — цвет песка:
  - `Белый`, `Серый`, `Жёлтый`, `Чёрный`, `Коричневый`
  - **Используем для вариаций:** разные цвета для разных объявлений
- **Availability** (необязательный, но используем) — доступность:
  - `В наличии`, `Под заказ`
  - **Используем для вариаций:** чередуем значения

### Пример структуры для ПЕСОК:

```xml
<Ad>
  <Id>sand_05.12_1</Id>
  <Category>Ремонт и строительство</Category>
  <Title>Песок карьерный</Title>
  <Description><![CDATA[<p>Описание товара</p>]]></Description>
  <Address>Московская область, Одинцово, ул. Примерная, 1</Address>
  <Price>960</Price>
  <Images>
    <Image url="https://disk.yandex.ru/photo1.jpg"/>
    <Image url="https://disk.yandex.ru/photo2.jpg"/>
  </Images>
  <GoodsType>Стройматериалы</GoodsType>
  <AdType>Товар от производителя</AdType>
  <Condition>Новое</Condition>
  <GoodsSubType>Сыпучие материалы</GoodsSubType>
  <BulkMaterialType>Песок</BulkMaterialType>
  <BulkMaterialSubType>Карьерный</BulkMaterialSubType>
  <PackagingType>Россыпью</PackagingType>
  <CompactionCoefficient>1.5</CompactionCoefficient>
  <MinSaleQuantity>5</MinSaleQuantity>
  <PriceFor>м³</PriceFor>
</Ad>
```

## ТИП ТОВАРА: ЩЕБЕНЬ (Сыпучие материалы)

### Специфичные обязательные параметры:

#### 1. Категория и тип
- **GoodsSubType**: `Сыпучие материалы`
- **BulkMaterialType**: `Щебень, гравий`
- **BulkMaterialSubType** (обязательный) — подтип:
  - `Щебень`
  - `Гравий`
- **RubbleType** (обязательный, если BulkMaterialSubType = 'Щебень') — тип щебня:
  - `Гранитный`
  - `Гравийный`
  - `Известняковый`
  - `Вторичный`
  - `Бутовый`
  - `Мраморный`
  - `Другой`
- **Fraction** (обязательный) — фракция (14 вариантов):
  - `5–20 мм`, `20–40 мм`, `40–70 мм`, `5–10 мм`, `3–10 мм`, `10–20 мм`, `1–4 мм`, `2–5 мм`, `3–6 мм`, `6–10 мм`, `8–12 мм`, `40–60 мм`, `40–100 мм`, `70–250 мм`

#### 2. Условия продажи (форма: Россыпью)
**ВАЖНО:** Форма продажи всегда `Россыпью` для всех товаров.

- **PackagingType**: `Россыпью` (всегда)
- **CompactionCoefficient** (обязательный) — коэффициент уплотнения, т/м³
  - Диапазон: от 0 до 6
  - Пример: `1.4`, `1.5`, `1.6`, `1.7`, `1.8`, `2.0`
  - **Используем для вариаций:** разные значения для создания уникальности
- **MinSaleQuantity** (обязательный) — минимальный заказ, м³
  - Диапазон: от 0 до 500
  - Пример: `1`, `3`, `5`, `7`, `10`, `15`
  - **Используем для вариаций:** разные значения для создания уникальности
- **PriceFor** (обязательный) — единица измерения цены
  - Значения: `м³`, `тонну`
  - Пример: `м³` или `тонну`
  - **Используем для вариаций:** чередуем между `м³` и `тонну`

#### 3. Необязательные параметры (ИСПОЛЬЗУЕМ ВСЕ для вариаций)
**ВАЖНО:** Используем все необязательные параметры по максимуму для создания большего количества вариаций характеристик.

- **FlakinessIndex** (необязательный, но используем) — лещадность:
  - `1 группа`, `2 группа`, `3 группа`, `4 группа`, `5 группа`
  - **Используем для вариаций:** разные группы для разных объявлений
- **ConcreteGrade** (необязательный, но используем) — марка прочности:
  - `М100`, `M200`, `M300`, `M400`, `M600`, `M800`, `M1000`, `M1200`, `M1400`
  - **Используем для вариаций:** разные марки для разных объявлений
- **FrostResistance** (необязательный, но используем) — морозостойкость:
  - `F15`, `F25`, `F50`, `F100`, `F150`, `F200`, `F300`, `F400`
  - **Используем для вариаций:** разные значения для разных объявлений
- **Availability** (необязательный, но используем) — доступность:
  - `В наличии`, `Под заказ`
  - **Используем для вариаций:** чередуем значения

## ПРАВИЛА ГЕНЕРАЦИИ ОБЪЯВЛЕНИЙ

### 1. Флагманское объявление
- **Характеристики:** все параметры соответствуют реальному товару
- **Заголовок:** только кириллица, без латиницы
- **Описание:** точное, без несоответствий
- **Для ПЕСКА:** `BulkMaterialSubType` — реальный тип песка, который есть в наличии
- **Для ЩЕБНЯ:** `RubbleType` и `Fraction` — реальные характеристики щебня, который есть в наличии
- **Необязательные параметры:** заполняем реальными значениями (Color, Availability и др.)

### 2. Дубли (варианты объявлений)
**ВАЖНО:** Используем все параметры (обязательные и необязательные) для создания максимального количества вариаций.

- **Заголовок:** вариации только с кириллицей (латиница только в описании)
- **Для ПЕСКА:** 
  - `BulkMaterialSubType` — на начальном этапе всегда "Карьерный", при масштабировании можно использовать другие типы
  - `CompactionCoefficient` — **фиксируем** корректное значение в соответствии с типом песка (не варьируем)
  - `MinSaleQuantity` — **фиксируем** 20 м³ (не варьируем)
  - `PriceFor` — чередуем `м³` и `тонну`
  - `Color` — разные цвета для вариаций (Белый, Жёлтый, Серый)
  - `Availability` — **фиксируем** "В наличии" (не варьируем)
- **Для ЩЕБНЯ:** 
  - `RubbleType` и `Fraction` — можно использовать комбинации, которых нет в наличии
  - `CompactionCoefficient` — корректное значение (не варьируем)
  - `MinSaleQuantity` — фиксируем (не варьируем)
  - `PriceFor` — чередуем `м³` и `тонну`
  - `FlakinessIndex` — разные группы (1-5)
  - `ConcreteGrade` — разные марки (М100-М1400)
  - `FrostResistance` — разные значения (F15-F400)
  - `Availability` — фиксируем "В наличии"
- **Описание:** может отличаться от характеристик, используем вариации текста с латиницей для уникализации
- **Фото:** одна ссылка на фото для каждого объявления

### 3. Проверка уникальности (двухуровневая)
**Для ПЕСКА:**

**Основные параметры (9 параметров):**
- Title, BulkMaterialSubType, Color, PriceFor, Price, Address, Block1_Variant, PhotoLink, LatinReplacements
- **Условие:** суммарно не менее 3 отличий для уникальности

**Блок 7 (9 параметров):**
- Объем, Самосвал, ХПЧ, ГП, Плотность, Модуль крупности, Фракция, ПНР, 𝜓
- **Условие:** не менее 5 отличий для уникальности

**Итоговая проверка:**
- Объявление уникально, если (в основных параметрах >= 3 отличий) И (в Блоке 7 >= 5 отличий)
- Объявление — дубль, если (в основных параметрах < 3 отличий) ИЛИ (в Блоке 7 < 5 отличий)

**Для ЩЕБНЯ:**
- Формула проверки будет определена при реализации генератора для щебня

## ДОПОЛНИТЕЛЬНЫЕ ПАРАМЕТРЫ (необязательные, но рекомендуемые)

### Контакты
- **ContactPhone** — контактный телефон
  - Формат: `+7 (495) 777-10-66` или `8 905 207 04 90`
- **ContactMethod** — способ связи
  - Значения: `По телефону и в сообщениях`, `По телефону`, `В сообщениях`

### Доставка
- **Delivery** — способы доставки
  - Значения: `Выключена`, `ПВЗ`, `Курьер`, `Постамат`, `Свой курьер` и др.
  - Можно указать несколько: `<Delivery><Option>ПВЗ</Option><Option>Курьер</Option></Delivery>`

### Продвижение
- **AdStatus** — услуга продвижения
  - Значения: `Free`, `Highlight`, `XL`, `x2_1`, `x2_7`, `x5_1`, `x5_7`, `x10_1`, `x10_7` и др.

### Дата публикации
- **DateBegin** — дата и время размещения
  - Формат: `dd.MM.yyyy HH:mm` или `dd.MM.yy 13:00`
  - Пример: `05.12.2025 10:00`
- **DateEnd** — дата окончания размещения
  - Формат: аналогично DateBegin

## ОШИБКИ И РЕШЕНИЯ

### Ошибка: "Id уже используется"
- **Причина:** Id повторяется в файле или уже существует в системе
- **Решение:** сгенерировать новый уникальный Id

### Ошибка: "Адрес не найден в профиле"
- **Причина:** Address не добавлен в профиль Avito
- **Решение:** добавить адрес в Профиль → Адреса → Адреса для объявлений

### Ошибка: "Неверный формат BulkMaterialSubType"
- **Причина:** указано значение, которого нет в списке
- **Решение:** использовать только значения из списка допустимых

### Ошибка: "Объявление заблокировано как дубль"
- **Причина:** слишком похожее объявление уже существует
- **Решение:** изменить Title, BulkMaterialSubType или Description

## ПРИМЕЧАНИЯ

1. **Один файл на все товары:** можно объединять разные типы товаров (Песок, Щебень и др.) в один XML-файл
2. **Порядок объявлений:** не важен, Avito обработает все объявления
3. **Обновление объявлений:** для обновления существующего объявления нужно указать его `AvitoId` и изменить нужные параметры
4. **Удаление объявлений:** удалить объявление из файла = перенести в архив (для полного удаления нужно удалить вручную через профиль)
