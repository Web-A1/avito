# Стратегия генерации объявлений (актуальная)

Цель: рабочая система масс‑постинга по песку, лучше конкурента, с автоматической уникализацией и готовым XML для ручной автозагрузки.

## Пайплайн генерации
- Вход: тип песка, адрес/локация, пул фото, желаемое количество объявлений.
- Генерация текста: блок 1 (вариативный) + блок 2 (фикс) + блок 3 (фикс) + блоки 4‑6 в случайном порядке + блок 7 (уникальные техпараметры).
- Уникализация: латиница 5–10% слов (обязательно в ключевых), разные разделители, порядок блоков 4‑6, вариативный блок 1, уникальный блок 7.
- Проверка дублей: двухуровневая (9 основных параметров и 9 параметров блока 7).
- Выход: массив объявлений → XML (см. docs/avito_rules.md) → ручная загрузка в кабинет Авито.

## Шаблон объявления (7 блоков)
- Блок 1: вступление (вариативные тексты, зависят от типа песка; для мытого — подстановка модуля крупности).
- Блок 2: применение (фикс для каждого типа песка, HTML `<ol>`).
- Блок 3: призыв к действию (фикс, `<strong>`).
- Блоки 4‑6: фиксированные тексты, но порядок перемешивается (6 перестановок): преимущества NERUDA, режим работы, ассортимент.
- Блок 7: технические характеристики (9 параметров, уникальны для каждого объявления).
- Разделители: 6 штук между блоками, варианты длины (27/35/39/43), пробелы, HTML‑обёртка (`<br> ... <br>` и вариации).

## Уникализация
- Латиница: 5–10% слов, обязательно минимум 1 замена в ключевых словах (песок, карьерный, немытый/сеяный/мытый, модуль крупности). Замены по визуально идентичным символам (а→a, е→e, о→o, с→c, х→x, р→p, у→y, и заглавные аналоги).
- Порядок блоков: фикс 1‑3, 7; блоки 4‑6 тасуются (6 вариантов).
- Разделители: все 6 могут отличаться, комбинация длины/пробелов/HTML.
- Блок 1: выбор из готовых вариантов по типу песка.
- Блок 7: всегда новая комбинация параметров.

## Параметры объявлений
- Варьируем: `PriceFor` (м³/тонну), `Color` (Белый/Жёлтый/Серый), `Price` (кратность 50 в заданных диапазонах).
- Фиксируем: `MinSaleQuantity` = 20 м³; `Availability` = "В наличии"; `PackagingType` = "Россыпью".
- CompactionCoefficient (по типу песка): немытый несеяный 1.40; сеяный немытый 1.70; сеяный мытый (мелкий/средний/крупный) 1.60.
- Техдиапазоны блока 7: объем 1000–100000 м³; ХПЧ 0.01–9.99 шаг 0.01; ГП 0.1–2.0 шаг 0.1; плотность по типу; модуль и фракция по типу; ПНР 0.50–1.00 шаг 0.05; 𝜓 0.10–2.00 шаг 0.10.

## Заголовки
- TOP‑5 (основная масса дублей): "Песок", "Песок карьерный", "Купить песок", "Песок с доставкой", "Песок доставка".
- Жирошкино‑варианты для Домодедово/Видное/Подольск/Бронницы (по всем типам песка).
- Флагманские точные названия (EXACT_TITLES) — одно на локацию, разные формулировки по типам песка и модулям.
- Заголовки только кириллицей, латиница — только в описании.

## Проверка дублей (2 уровня)
- Основные 9: Title, BulkMaterialSubType, Color, PriceFor, Price, Address, Block1_Variant, PhotoLink, LatinReplacements. Требуется ≥3 отличия.
- Блок 7 (9): объем, самосвал (марка+номер), ХПЧ, ГП, плотность, модуль, фракция, ПНР, 𝜓. Требуется ≥5 отличий.
- Уникально: если выполнены обе границы (≥3 и ≥5). Иначе — дубль.

## Разделители (варианты)
- Длина: 27 / 35 / 39 / 43 подчёркиваний.
- Пробелы: без, в начале, в конце, по обе стороны.
- HTML: `<br> ___________________________________<br> <br>` и вариации (без пробелов, без пустой строки, без стартового тега и т.д.).

## План реализации (коротко)
1) Валидатор дублей (готов).  
2) Генератор объявлений: раскладка заголовков/цен/цветов/PriceFor, привязка адресов и фото, вызов генерации описания и блока 7, проверка дублей.  
3) XML‑генератор: сбор `<Ads><Ad>` с CDATA Description, Id `sand_DD.MM_nn`, обязательные поля и изображения.  
4) Скрипт/CLI: читаем данные, генерируем N объявлений, сохраняем XML в `output/`.  
5) Тест/проверка: быстрый прогон 1–2 объявлений, ручная проверка структуры XML.  
6) Расширение: адреса/фото из data/*.json, масштабирование до 50–100 объявлений на локацию.

## Данные и зависимости
- Нужны `addresses.json` (локации) и `photos.json` (списки URL) — пока заглушки.
- Все тексты блоков и диапазоны параметров продублированы в коде (`src/constants/*`, `src/constants/block1And2.js`).

## Исследование конкурента (сжатое)
- 20 проверенных объявлений: во всех латиница, общий шаблон + уникальные техпараметры.
- Массовые выкладки пакетами (по 9 за минуту), без блокировок на момент проверки.
- Часто несоответствие характеристик/описания по щебню.
