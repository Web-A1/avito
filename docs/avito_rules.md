# Правила и структура XML для Авито (актуально)

## Формат XML
```xml
<Ads formatVersion="3" target="Avito.ru">
  <Ad>
    <!-- Параметры объявления -->
  </Ad>
</Ads>
```
- Кодировка UTF-8, до 50 000 `<Ad>` в файле.
- Description в CDATA, разрешены теги `p, br, strong, em, ul, ol, li`.

## Обязательные поля
- `Id` — `{тип}_{ДД.ММ}_{номер}`, не менять после публикации.
- `Category` — `Ремонт и строительство`.
- `Title` — до 100 символов, без цены/контактов.
- `Description` — до 7500 символов.
- `Address` — должен быть в профиле Авито (или `Latitude/Longitude`/`SellerAddressID`).
- `Images` — 1–10 JPEG/PNG до 25 МБ, `<Image url="..."/>`.
- `GoodsType` — `Стройматериалы`.
- `AdType` — `Товар приобретен на продажу` или `Товар от производителя`.
- `Condition` — `Новое` или `Б/у`.
- `GoodsSubType` — `Сыпучие материалы`.

## Песок (BulkMaterialType = "Песок")
- `BulkMaterialSubType` (обязательно): `Речной`, `Карьерный`, `Морской`, `Кварцевый`, `Перлитовый`, `Керамзитовый`, `Мраморный`, `Доломитовый`, `Термозитный`.
- `PackagingType`: всегда `Россыпью`.
- `CompactionCoefficient`: обязательный, но фиксируем корректное значение по типу песка (не варьируем).
- `MinSaleQuantity`: фиксируем 20 м³ (не варьируем).
- `PriceFor`: `м³` или `тонну` (используем для вариаций).
- `Price`: целое число в рублях.
- Необязательные, но заполняем: `Color` (Белый/Серый/Жёлтый/Чёрный/Коричневый), `Availability` (всегда "В наличии").

## Щебень (BulkMaterialType = "Щебень, гравий")
- `BulkMaterialSubType`: `Щебень` или `Гравий`.
- Если `Щебень`: `RubbleType` (Гранитный/Гравийный/Известняковый/Вторичный/Бутовый/Мраморный/Другой).
- `Fraction`: один из 14 значений (5–20 мм, 20–40 мм, ... 70–250 мм).
- Остальное аналогично песку: `PackagingType` = `Россыпью`, `CompactionCoefficient` фиксируем корректно, `MinSaleQuantity` фикс, `PriceFor` варьируем, `Availability` = "В наличии". Необязательные: `FlakinessIndex`, `ConcreteGrade`, `FrostResistance`.

## Проверка дублей (для песка)
- Основные 9: Title, BulkMaterialSubType, Color, PriceFor, Price, Address, Block1_Variant, PhotoLink, LatinReplacements.
- Блок 7 (9): объем, самосвал (марка+номер), ХПЧ, ГП, плотность, модуль, фракция, ПНР, 𝜓.
- Уникально: ≥3 отличия по основным и ≥5 по блоку 7; иначе дубль.

## Чек-лист перед выгрузкой
- [ ] Все обязательные поля заполнены, Id уникальны.
- [ ] Description ≤ 7500 символов, Title без цены/контактов.
- [ ] Address есть в профиле, ссылки на фото валидны.
- [ ] `PackagingType` = `Россыпью`, `CompactionCoefficient` в диапазоне 0–6 и соответствует типу.
- [ ] `MinSaleQuantity` = 20 (песок), `Availability` = "В наличии".
- [ ] BulkMaterialSubType/RubbleType/Fraction из списка допустимых.
- [ ] Проверка на дубли пройдена (правило ≥3 и ≥5).

## Типичные ошибки
- Повторяющийся `Id` → сгенерировать новый.
- Адрес не в профиле → добавить в адреса аккаунта.
- Недопустимое значение `BulkMaterialSubType` → использовать список допустимых.
- Блокировка за дубль → изменить Title/BulkMaterialSubType/Description.
